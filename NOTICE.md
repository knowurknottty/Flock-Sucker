# Flock-Sucker — Project Identity and Attribution

Flock-Sucker is an independently maintained **Inversion Labs** Android counter-surveillance and wireless situational-awareness project.

The project was inspired by **MaxwellDPS/Flock-You-Android**. Inversion Labs preserves that credit because the upstream project supplied the starting idea and historical foundation from which this variant evolved.

Flock-Sucker is **not** an official release of that upstream project. Inversion Labs is not claiming affiliation with, endorsement by, or maintenance authority over the upstream project. Current Flock-Sucker source, package identity, release artifacts, evidence architecture, detector hardening, device-specific work, and ongoing development are maintained as the Inversion Labs variant.

The canonical Android identity for current Flock-Sucker releases is:

`com.inversionlabs.flocksucker`

Historical documents and repository history may contain earlier upstream names or the former package identity because they record real development history. Those historical references are not the current product identity.
