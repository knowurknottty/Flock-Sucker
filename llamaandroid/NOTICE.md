# llamaandroid attribution

This module is adapted from the Android example/binding distributed with
[`ggml-org/llama.cpp`](https://github.com/ggml-org/llama.cpp), which is included
in this repository as the pinned `third_party/llama.cpp` git submodule.

The adaptation adds Flock-Sucker integration and runtime configuration while
keeping the upstream implementation independently traceable through the pinned
submodule revision. See the upstream repository for its license and notices.
